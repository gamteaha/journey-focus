# 사막 도트 여행

- 입장: `/?destination=desert` → 공통 승차권/교통카드 → `/desert/?ticket=…`
- 지구본의 사막 표시는 테마 선택 지점이며 실제 철도 위치가 아니다. 7개 정거장과 풍경 모두 가상이다.
- `public/desert/src/pixel-scene.mjs`가 Canvas 2D로 모래언덕, 피라미드, 오아시스, 야자수, 유적과 낙타를 직접 그린다. 생성형 AI 호출이나 외부 지도 API 없이 실행한다.
- 먼 풍경과 가까운 풍경의 이동 속도를 달리하고 정수 좌표/최근접 확대를 사용한다. 새벽·낮·노을·별밤, 모래바람 강도를 설정할 수 있다.
- 집중시간 추천은 정거장 사이 5분을 기준으로 한다. 유한 여정은 선택 시간에 도착 표시를 맞추며 창밖 속도는 일정하다. 무제한 여정은 구간 끝에서 왕복하고 사용자가 종료한다.
- 공통 티켓과 로딩 화면을 재사용한다. 객실은 인천 데모 기반의 2D 좌석 선택 화면이며 3D 사막 객실은 아니다. 캐릭터 자산은 기존 인천의 횃불이를 공유한다.
- 사막 승차권은 `journey-focus-desert-pass-v1`, 완료 기록은 `journey-focus-desert-history`에 분리 저장한다. 다른 여행지 승차권은 사용할 수 없다.
- 검증: 여정 단위 테스트, Cloudflare 경로/정적 자산 테스트, 실제 브라우저의 발급→착석→출발→일시정지 및 시간대/모바일 화면 확인.
