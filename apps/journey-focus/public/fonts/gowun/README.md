# Gowun fonts

Bundled from Google Fonts on 2026-11-06, using the unmodified WOFF2 files and Unicode ranges returned by:

https://fonts.googleapis.com/css2?family=Gowun+Batang:wght@400;700&family=Gowun+Dodum&display=swap

- Gowun Batang 400 / 700: https://github.com/yangheeryu/Gowun-Batang
- Gowun Dodum 400: https://github.com/yangheeryu/Gowun-Dodum
- Original font URLs are recorded in `manifest.json`.
- `fonts.css` changes only the source URLs to local paths. Unicode-range loading means the browser requests only the chunks needed for displayed characters.
- Both font families use SIL Open Font License 1.1; see `OFL-Batang.txt` and `OFL-Dodum.txt` for their original copyright and license notices.
- No OS font installation is required. Font display uses `swap`.
