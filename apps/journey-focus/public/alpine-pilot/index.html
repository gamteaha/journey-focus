객실과 풍경 안내

제공해 주신 모노레일 모델을 사용한 임시 객실입니다. 실제 베르니나 열차의 객실을 재현한 모델은 아닙니다.

오른쪽 창가 좌석만 선택할 수 있어요. 의자를 누르면 색이 바뀌고, 횃불이 옆의 ‘앉기’를 누르면 이동해서 앉습니다. 캐릭터는 현재 혼자 탑승합니다.

스위스의 실제 OSM 선로 중 약 1.6km 야외 구간을 이동합니다. 객실 카메라의 위치·시야각을 풍경 카메라에 함께 반영합니다. 바닥 높이는 지형 위 1.5m 시험값이며, 실제 차량과 선로 높이를 측량해 맞춘 것은 아닙니다. 배경을 그린 지도는 실시간 영상이 아닙니다.

공부한 시간은 출발 후 실제 재생 시간만 쌓입니다. 위치 슬라이더를 움직이거나 화면을 벗어나면 잠시 멈춥니다. 승차권의 목표시간까지 5분마다 방향을 바꾸며 같은 구간을 왕복합니다. 무제한은 직접 멈출 때까지 이어집니다. 이동 방향이 바뀌어도 객실과 창밖 시야는 회전하지 않습니다.
