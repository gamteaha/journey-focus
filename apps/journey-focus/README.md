# Journey Focus · 창밖으로 떠나는 집중

2호선 본선 43개 역의 실제 OSM 선로, 서울 T Data 역 정보와 브이월드 3D 지도 API를 사용하는 실행 앱입니다. 시간별 도착역 추천과 [∞ 무제한 순환](docs/unlimited-loop.md)을 지원합니다. 경춘선 관련 자료는 이전 풍경 실험으로 남아 있습니다.

최신 완성도 개선과 검증: [release-candidate.md](docs/release-candidate.md). 실사 렌더링의 다음 단계: [rendering-roadmap.md](docs/rendering-roadmap.md).

## 실행

1. Node.js 24 이상이 필요합니다. 외부 npm 패키지 설치는 필요 없습니다.
2. `BAI/.env.local`에 아래 항목을 입력합니다. 기존에 입력한 값은 그대로 사용합니다.

   ```dotenv
   VWORLD_API_KEY=본인의_브이월드_키
   VWORLD_SERVICE_URL=http://localhost:5173
   TDATA_API_KEY=본인의_T_Data_키
   ```

3. 이 폴더의 `start.cmd`를 실행하거나 PowerShell에서 다음 명령을 실행합니다.

   ```powershell
   node server.mjs
   ```

4. 브라우저에서 **http://localhost:5173** 을 엽니다. 키 등록 주소에 맞춰 `127.0.0.1` 대신 `localhost` 사용을 권장합니다. 키를 변경하면 서버를 다시 시작합니다.

포트가 사용 중이면 기존 서버를 종료하고 실행하세요. `.html` 파일을 직접 여는 방식은 지원하지 않습니다. 서버는 로컬 인터페이스에만 바인딩되며 외부 공개용으로 설계되지 않았습니다.

## 사용

- 기본 구간: 백양리 → 강촌. T Data에서 받은 경춘선 19개 역 중 출발·도착을 선택할 수 있습니다.
- 화면 품질은 자동 / 균형 / 높은 디테일 / 가볍게로 조절합니다. 품질과 역·시간·시점 설정은 저장되며 소리와 세션은 자동 재생하지 않습니다.
- 1분 체험 / 5분 / 25분 / 50분 목표시간. **실제 열차 운행시간이 아닙니다.**
- 창가 방향 / 넓게 보기, 집중 화면, 선택적으로 켜는 합성 열차 소리.
- 시작 → 일시정지/재개 → 완주 또는 중간 종료. Space로 일시정지/재개할 수 있습니다.
- 완료/종료 기록은 브라우저 localStorage에 최대 30개 보관하며 기록 창에서 삭제할 수 있습니다. 실행 중 새로고침을 하면 현재 세션은 복구되지 않습니다.

## 실제 데이터와 현재 한계

| 항목 | 상태 |
| --- | --- |
| 브이월드 키 | 공식 SDK 인증 유효 응답 확인 |
| 3D 지도 | WebGL API 3.0으로 지형·영상 실제 로딩 |
| 역 좌표 | T Data 역사마스터 경춘선 19개 역 수신 |
| 기본 구간 이동 경로 | **백양리–강촌 OSM 철도 선형 45개 좌표** (수평 선형 후보, 현장 미검증) |
| 다른 구간 이동 경로 | 역 사이 좌표 보간. 실제 철도 선형 아님 |
| 높이 | 지형 상대 3~300m 조절, 초기 추천 30m. 실제 선로/창문 높이 미검증 |
| 터널·정차·운행시간 | 미구현 / 미검증 |
| 집중 효과 | 검증하지 않음 |

기본 구간인 백양리–강촌(역방향 포함)은 OSM 철도 선형을 사용합니다. 출발·도착 좌표는 T Data 역 좌표에서 각각 약 14.2m와 3.2m 떨어진 OSM 선로 노드입니다. 선로의 높이와 운행 방향은 현장 검증하지 않았으며, 터널도 지형 위에서 조망합니다. 다른 역 조합은 직선 보간이므로 산과 건물을 가로지를 수 있습니다. 열차에 밀착한 완성된 창밖 풍경이 아니라 실제 공간정보 연결과 시간 동기화를 확인하는 실험입니다.

세션 종료는 렌더링과 독립된 타이머로 예약하며, 합성 음향은 Web Audio 시간축에서도 종료를 예약합니다. OS 절전·브라우저 프로세스 정지까지 실행을 보장하는 것은 아닙니다.

FPS는 지도 프레임 렌더 횟수의 2초 구간 측정치입니다. 다른 기기의 성능을 보장하지 않습니다. 하드웨어 가속, 네트워크, 지형·영상 품질에 따라 차이가 납니다. 후처리/AI 변환은 적용하지 않았습니다.

## 키와 데이터 처리

- `.env.local`은 Git 제외 규칙이 적용됩니다. 키를 소스 파일이나 문서에 옮겨 적지 마세요.
- T Data 키는 서버에서만 사용하며 브라우저 응답에 포함하지 않습니다. 결과는 서버 메모리에 1시간 보관해 반복 요청을 줄입니다.
- **브이월드 키는 브라우저 SDK를 로딩할 때 브라우저에 전달됩니다.** `.env.local`이 브라우저용 키를 숨겨 주는 것은 아닙니다. 키에 등록한 서비스 주소와 사용량을 관리해야 합니다.
- 브이월드 지형/3D 자산은 서버 파일로 저장하거나 추출하지 않습니다. SDK의 로고와 출처 표시를 유지합니다. 변경·재가공·별도 저장이 필요하면 제공기관의 이용조건을 먼저 확인합니다.
- 정적 파일은 명시적 허용 목록만 제공하며 `.env`, `.git`, 서버 소스, 상위 디렉터리 접근을 차단합니다.
- 팀원에게는 키가 제외된 소스를 공유하고 각자 자신의 키를 사용하도록 합니다. 공개 운영 전 도메인 등록과 운영키 절차를 확인해야 합니다.

## 풍경 미리보기 300m

**백양리 → 강촌**을 선택하고 지도 위 **풍경 미리보기**를 누릅니다. 모델이 준비되면 **30초 이동**을 눌러 보세요. 일시정지, 처음으로, 위치 슬라이더 및 원래 지도로 돌아가기를 지원합니다. 학습 세션이 진행 중이면 일시정지하며, 시안의 30초는 학습 시간에 합산하지 않습니다.

- OSM 선형의 출발 후 150~450m 구간을 이동합니다. 원본 브이월드 지형을 그대로 사용합니다.
- 주택 후보 5곳(지붕/벽 재질과 창문을 갖춘 자체 glTF) 중 평탄한 자리만 기초와 함께 표시합니다. 경량 침엽수/활엽수 모델 10개, 초록 잎 식물 18군락, 휘어진 풀잎의 군락 72개, 전봇대 8개를 추가하며 주택과 겹치는 식생은 숨깁니다.
- **집/식생/전봇대의 종류·배치는 재구성 시안이며 실제 현장 배치를 검증한 자료가 아닙니다.** 카메라는 주변 지형을 평활화한 높이 + 6m 기준으로 이동하며 실제 철도 표고가 아닙니다. 원본 산의 영상 화질도 개선한 것이 아닙니다.
- 배치 높이는 SDK로 지형 표고를 메모리에서 조회합니다. 브이월드 자산이나 지형 파일을 추출·저장하지 않습니다.
- 시안 동안 원본 건물 레이어를 공식 표시 기능으로 숨기고, 종료/오류 시 기존 상태로 복원합니다.
- CC0 자산은 약 27MB이며 앱에 포함돼 있습니다. 최초 로딩과 성능은 기기에 따라 달라집니다. 별도 AI API 키나 결제는 필요하지 않습니다.
- 출처와 제작/검증 기록: [scenery-pilot.md](docs/scenery-pilot.md).
- 풀의 형상·배치와 주택 기초 보정 및 측정: [scenery-naturalness.md](docs/scenery-naturalness.md).

## 실사와 비교하기 (2026-11-03 추가)

지도 위 **실사와 비교하기**를 누르면 지도와 참고 화면이 나란히 나타납니다. 진행 중 세션은 일시정지하며, 비교를 마쳐도 자동 재개하지 않습니다.

1. **추천 시점 / 이전 화면 / 낮은 시점 실험**으로 차이를 확인합니다. 추천은 지형 위 30m, 진행 방향의 왼쪽 90°, 경사 -4°, 화각 65°, 전체 건물 상세도와 정밀 지형입니다. 이전 화면은 110m/LoD4 기준입니다. 낮은 시점은 8m이며 실제 선로 높이를 뜻하지 않습니다.
2. 참고 영상 불러오기를 누르면 사용자가 공유한 경춘선 상봉–춘천 주행 영상을 YouTube 공식 플레이어로 엽니다. 영상 시각을 입력하거나 현재 시각 가져오기를 사용합니다. 재생 제한/네트워크 오류 시 원본 링크로 확인할 수 있고 다시 불러오기도 가능합니다.
3. **내 사진** 탭에서 JPG/PNG/WebP(20MB 이하)를 선택할 수 있습니다. 사진은 브라우저 object URL로만 표시하고 서버에 업로드하지 않습니다.
4. 지도 위치 슬라이더로 지점을 맞추고, 방향/높이/경사/화각을 조절합니다. 영상 시각과 지도 진행률은 **자동 동기화되지 않습니다**. OSM 지상 후보 버튼은 터널이 아니라고 표기된 선형 구간의 중간으로 이동합니다. 현장 지상 여부는 미검증입니다.
5. 건물을 **전체 상세도 / LoD1~4 / 끄기**로 비교하고 지형 정밀도를 전환합니다. 전체 모드를 기본으로 변경했습니다. 한 번에 하나의 레이어만 표시합니다. 정밀 모드는 제공된 지형의 세부 수준만 조절하며 원본에 없는 나무나 건물을 생성하지 않습니다.
6. 비교 지점 이름·메모와 함께 저장하면 경로, 영상 시각, 진행률, 카메라/레이어 설정을 이 브라우저에 보관합니다. 사진 원본은 저장하지 않습니다. 다른 경로에는 잘못 복원하지 않도록 차단합니다. JSON으로 내보낼 수 있습니다.

실측 조사: 백양리 인근 동일 위치·시점에서 LoD4의 선택 객체 0개, 전체 레이어 251개를 확인했습니다. 건물 형태가 추가되지만 단순 모형은 실제 지붕/벽 재질과 다릅니다. 이는 한 시점의 SDK 진단값이지 지역 전체 건물 수가 아닙니다. 상세 결과와 다음 제작 단계는 [풍경 조사 기록](docs/visual-investigation.md)을 참고하세요.

## 검증

```powershell
npm.cmd test
npm.cmd run check
```

자동 브라우저 점검 도구는 `scripts/browser-check.mjs`입니다. 별도 테스트 프로필의 Chrome이 CDP 포트 9223에서 실행 중이고 앱 서버가 켜져 있어야 합니다. 일반 실행에는 CDP나 Chrome 테스트 설정이 필요 없습니다.

```powershell
node scripts/browser-check.mjs --complete
node scripts/comparison-check.mjs
node scripts/comparison-errors-check.mjs
```

실제 지도 초기화, 19개 역 수신, 시작/일시정지/재개/종료, 새 시간 선택 시 초기화, 브라우저 기록, 시점 전환, 집중 화면, 모바일 가로 넘침 및 실제 1분 완주를 점검합니다. 결과 캡처는 `BAI/tmp/journey-focus-*.png`에 저장됩니다.

## 파일 구성

- `server.mjs`: 설정 읽기, 안전한 정적 파일 제공, T Data API와 지도 문서 제공
- `src/session.mjs`: 단일 경과시간 기반 세션 시계
- `src/route.mjs`: 경춘선 역 순서와 거리/좌표 보간
- `public/map.*`: 브이월드 SDK와 카메라 제어를 격리한 지도 프레임
- `public/app.mjs`: 여정 설정, 타이머, 상태 안내, 기록
- `public/audio.mjs`: 사용자 선택에 의한 합성 환경음
