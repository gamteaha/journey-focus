# 산비탈 숲 비교 시안 · 2026-11-04

로컬 지도 좌측 상단의 **산 숲 비교 · 켜기**로 활성화한다. 다시 누르면 원본으로 돌아간다. 기본은 꺼짐이며 공개 배포 소스에는 반영하지 않았다.

백양리 기준 북동쪽의 작은 산비탈 패치에 절차적으로 만든 나무 이미지를 지형 높이에 세워 숲의 실루엣을 보강한다. 샘플 지형 높이 95~650m 범위만 사용한다. 확인 시 3,129개가 배치됐다. 실제 산림 경계·수종·수목 위치를 검증한 자료가 아니다. 브이월드 영상 자체를 수정하거나 추출하지 않는다. 추가 유료 API가 필요 없다.

이미지는 앱에서 Canvas로 생성하며 가벼운 billboard 방식이다. 가까운 거리에서 보는 정교한 3D 나무나 실사 재구성이 아니다. 경계, 반복 무늬, 원본 영상과 색감 차이가 남아 있다. 기존 300m 근경 모델을 대체하는 기능도 아니다.

실제 SDK에서 켜기와 3,129개 배치 및 화면 캡처를 확인했다. 기존 테스트 48개 통과, 새 모듈 문법 검사 통과. 테스트 당시 T Data 역 조회에서 502가 발생하여 전체 세션 이동 검증은 하지 않았다. 다기기 성능 측정은 미완료다.

소스: public/forest.mjs, 연결: public/map.mjs, 제공 경로: server.mjs. hosted에는 아직 복사하지 않았다.
