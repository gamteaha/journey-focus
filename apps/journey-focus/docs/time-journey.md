# 시간 계기판과 실제 도착역 추천

집중시간을 00:00 형식의 시·분 계기판에서 고른다. 위·아래 버튼, 숫자 직접 입력, 키보드 방향키와 빠른 시간 버튼을 지원한다. 범위는 1분–2시간이며 1분 단위로 승차권과 설정 저장에 반영된다. 0분 또는 2시간 초과 입력은 발급할 수 없고, 입력을 떠나면 마지막 유효 시간으로 돌아간다.

계기판 오른쪽에는 추천 정거장 수와 실제 경유역을 표시한다. 정거장 수는 출발역을 제외하고 도착역을 포함한 이동 구간 수다. 시간을 바꾸면 추천 도착역이 자동 선택된다. 출발역을 바꿔도 다시 추천하며, 도착역을 직접 고른 경우에는 추천 패널에서 다시 적용할 수 있다. 표와 카드의 설정 UI는 인쇄물 바깥에 두고, 종이표/교통카드는 기존 실제 비율과 공통 축척을 유지한다.

## 선로와 역

지원 범위는 한양대–뚝섬–성수–건대입구–구의–강변–잠실나루 7개 역이다. `public/data/line2-surface.json`은 연결된 OSM 선로 81개 좌표, 4개 way의 ID와 원본 API URL, 역의 선로 위 기준점, 라이선스 및 수집 시각을 포함한다.

- OSM way: 1458437482 → 625534094 → 628671356 → 628671358. 양 끝 노드가 일치하는지 검사했다.
- 출처: [OSM 공식 읽기 API](https://wiki.openstreetmap.org/wiki/API_v0.6), © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright).
- 역 중심은 서울시 T Data 지하철역 GEOM 응답으로 확인했다. API의 `구의(광진구청)`, `강변(동서울터미널)` 같은 부역명은 기본 역명으로 정규화한다.
- 역 중심을 기존 선로의 가장 가까운 선분 위에 투영해서 기준점을 삽입한다. 선로 자체를 직선으로 바꾸거나 역/건물을 향해 이동시키지 않는다. 기준점과 역 중심의 수평 차이는 0.8–5.4m다.
- 방향을 바꿀 때에는 같은 선로 좌표를 역순으로 사용한다. 중간역을 통과하면 객실 전광판의 현재/다음 역도 실제 경유 순서대로 갱신된다.
- 수평 선형 후보이며 선로 표고, 고가 높이, 열차 운행 방향과 운영 시간표까지 검증한 자료는 아니다. 기존 30m 조망 높이는 계속 시험값이다.

재현: 앱 디렉터리에서 `node scripts/build-city-rail.mjs`. 원본 응답은 무시되는 루트 `tmp/city-rail-source/`에만 저장하며, 배포 파일에는 필요한 선로만 남긴다. `--cached`는 이미 받은 원본으로 재생성한다. VWorld 자산 또는 API 키를 저장하지 않는다.

## 추천 속도

기존 성수–건대입구를 25분 동안 보는 속도(약 0.795m/s)를 기준으로 삼는다. 양 방향의 실제 도착역에 대해 선로 길이÷선택 시간을 계산하고, 기준 속도와의 비율 차이가 가장 작은 역을 추천한다. `src/journey.mjs`가 계산하며 정거장 개수를 시간에 비례하는 가짜 숫자로 만들지 않는다.

성수 출발 예:

| 집중시간 | 추천 도착역 | 정거장 수 | 선로 거리 | 기준 속도와 차이 |
|---|---|---:|---:|---:|
| 25분 | 건대입구 | 1 | 약 1.26km | 약 +5% |
| 60분 | 구의 | 2 | 약 2.81km | 약 −2% |
| 90분 | 강변 | 3 | 약 3.76km | 약 −12% |
| 120분 | 잠실나루 | 4 | 약 5.54km | 약 −3% |

역 사이 거리가 일정하지 않으므로 임의의 시간에 정확히 도착하면서 속도까지 완전히 같게 할 수는 없다. 추천은 비슷한 속도를 선택하는 방식이며 실제 열차 운행시간이나 고정 정차시간이 아니다. 1–9분은 짧은 체험이라는 안내를 표시한다. 지원 범위 끝이나 짧은 시간에서 비슷한 속도의 역이 없으면 가장 가까운 후보라는 안내를 표시한다. 직접 도착역을 고르면 추천 경로와 속도가 달라질 수 있음을 알려 준다.
