## 선형 데이터

백양리–강촌 기본 구간은 OpenStreetMap 공식 읽기 API에서 가져온 철도 선형 45개 좌표를 사용한다. 계산상 길이는 약 5.30km, 이 중 OSM에 tunnel=yes로 표기된 경로 길이는 약 3.54km이다. 이 구간을 모두 자연풍경의 지상 구간이라고 해석해서는 안 된다. 현재 터널 내부 장면은 없으며 터널도 지형 위에서 조망한다.

출발·도착 OSM 노드는 T Data 역 중심에서 각각 약 14.2m, 3.2m 떨어져 있다. 실제 운행 방향, 수직 선형과 현장 상태는 검증하지 않았다. OSM 원본 way ID, 출처, 수집 시각, ODbL 라이선스 정보는 데이터 파일에 포함했다. 다른 역 조합은 실제 선로가 아닌 역 사이 보간 경로이다.
