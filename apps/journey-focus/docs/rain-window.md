# 비 오는 창가와 습기

창밖 풍경의 기본 날씨는 `비 · 습기`, 습기 강도는 65%다. 열차 안 왼쪽 위 **설정 → 창밖 날씨**에서 맑음, 잔잔한 비, 비·습기를 비교하고 습기를 0–100%로 조절한다. 선택은 이 브라우저에 저장한다.

브이월드 지도 위에 앱의 유리창 표현을 겹치는 방식이다. 브이월드 내장 비 API나 실제 날씨 API를 호출하지 않는다. 건물에 가려지는 3D 강수, 도로의 젖은 재질, 물리적인 굴절은 구현 범위가 아니다. 캐릭터 객실은 별도의 3D 장면이므로 이 효과는 창밖 보기에서 표시한다.

- `public/window-weather.mjs`: Canvas 2D로 먼 빗줄기 72개와 가까운 유리 물방울 24개를 그린다. 물방울은 다른 속도로 흐르며 일부에 물자국과 작은 하이라이트를 표시한다.
- `public/window-weather.css`: 배경 흐림과 차분한 색감, 가장자리의 옅은 안개를 합성한다. 습기 65%일 때 흐림은 약 2.9px, 최대 4.5px다. 흐림을 지원하지 않는 브라우저에서는 색과 안개·빗방울을 유지한다.
- 효과는 지도 위, 창틀과 UI 아래에 놓인다. 전광판·시간·버튼을 흐리지 않고 포인터 입력을 받지 않는다. 브이월드/OSM 출처 표시가 있는 아래 62px는 효과 영역에서 제외한다.
- 캔버스 너비는 최대 1000px, 그리기는 최대 30fps로 제한한다. 이는 지도 자체의 FPS 보장이 아니다. 객실·승차권·맑음·다른 탭에서는 애니메이션을 멈추고, 움직임 줄이기 설정에서는 정지된 빗방울을 표시한다. 페이지를 떠날 때 관찰자와 이벤트를 정리한다.
- 브이월드 SDK나 지도 타일을 다시 불러오지 않고 날씨만 바꾼다. 지도 필터와 시간/추천 경로 계산은 기존 선택을 유지한다.

검사: `node scripts/weather-check.mjs`. 실제 브이월드의 맑음/비/습기 비교, 강도 저장, 출처 영역 보호, 입력 통과, 그리기 크기·빈도 제한, 움직임 줄이기, 객실 전환·맑음에서 정지, 모바일 배치를 확인한다. 캡처와 결과는 루트 `tmp/weather-qa/`에 저장한다.

관련 문서: [CSS backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter), [Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API). 현재 브이월드 SDK의 공식 내장 강수 API 지원 여부는 이번 조사로 확인하지 못했다.
