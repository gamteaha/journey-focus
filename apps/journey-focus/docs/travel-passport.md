# 공통 여행 화면 · 여권 · 세계여행

2026-11-07 구현. 기존 서울, 인천, 스위스, 사막은 처음부터 열려 있다. 추가 맵만 집중 도장으로 해금한다.

## 공통 화면

- 왼쪽 위: 설정, 소리, 여권. 오른쪽 위: 객실·캐릭터 / 창밖 풍경.
- 출발, 일시정지, 이어가기, 종료와 시간 표시를 같은 위치에 배치한다.
- 객실과 창밖을 바꿔도 집중은 계속된다. 브라우저 탭을 떠나면 일시정지한다.
- 소리: 환경음 / 음악 / 함께 듣기. 음악·열차·자연음 각각 음량과 켜기/끄기를 저장한다.
- 각 지역의 원래 풍경·좌석·상세 설정은 유지한다. 음악은 브라우저에서 합성하며 지역별 악곡 설정을 사용한다. 유료 생성 API나 유튜브 재생을 호출하지 않는다.

## 완료 승차권과 도장

5분 이상인 유한 여정을 완주하거나, 무제한 여정에서 5분 이상 집중하고 종료하면 도장 1개를 받는다. 유한 여정을 중간에 종료하거나 1분 체험을 끝내면 승차권만 받는다. 같은 여정의 중복 완료는 도장을 중복 지급하지 않는다.

완료 화면에서 날짜·경로·집중시간이 담긴 승차권 PNG를 저장할 수 있다. 여권에서 누적 도장, 방문 지역, 최근 30장 승차권을 볼 수 있다.

- 누적 도장 **3개**: 새 가상 맵 **달빛 오아시스** 해금. 달빛 호수, 야자수와 반딧불을 그리는 도트 풍경과 가상 정거장 5곳.
- 기존 4곳과 오아시스까지 **5개 지역 도장 모두 수집**: **세계여행 ∞** 타이틀 및 무한 순환 모드 해금.

같은 지역을 반복 완주해도 도장은 쌓이지만 세계여행 타이틀은 모든 지역 방문이 필요하다. 가격·결제·계정 기능은 없다.

## 세계여행

서울 → 인천 → 스위스 → 사막 → 달빛 오아시스 → 서울 순서로 반복한다. 각 구간은 5분이며 실제 앱의 기존 렌더러를 로드하고 자동 착석·출발한다. 완료 후 5초 환승 대기 화면에서 바로 환승, 대기, 종료를 고를 수 있다. 로딩·환승·일시정지 시간은 누적 집중시간에서 제외한다.

## 저장과 유지보수

- 여권: localStorage `journey-focus-passport-v1`.
- 소리: localStorage `journey-focus-sound-v2` (기존 사막 설정을 초기 이전).
- 세계여행 상태: sessionStorage `journey-focus-world-tour-v1`.
- 새 맵 추가: `src/passport.mjs`의 DESTINATIONS/WORLD_ORDER, 목적지 UI, 승차권 팩토리, world-tour의 이동 경로와 해당 화면의 travel-shell 어댑터를 함께 추가한다.
- 기록은 이 브라우저에만 저장한다. 브라우저 데이터 삭제·다른 기기·다른 도메인에 자동 동기화되지 않는다. 기존의 지역별 과거 기록은 그대로 유지하며 새 여권 도장을 소급 지급하지 않는다.

## 2026-11-08 여권·집중 기록 업데이트

- 완료하면 횃불이와 도장 누르는 애니메이션을 표시한다. 5분 미만/중도 종료에는 도장 획득으로 표시하지 않는다. 모션 줄이기 설정도 따른다.
- 여권은 횃불이 표지를 눌러 펼치는 두 페이지 책이다. 받은 도장을 눌러 다시 찍는 동작을 볼 수 있고, 이 동작은 도장 개수를 늘리지 않는다.
- 개인 학습 시간 순위는 이 브라우저에 기록된 실제 집중초로 계산한다. 동점은 같은 순위다. 여권에서 상위 5개와 누적 기록, 완료 화면에서 해당 여정의 개인 순위를 확인한다. 서버/다른 사람 순위는 없다.
- `학습 기록 공유`는 1200×900 PNG를 만든다. 파일 공유가 지원되면 사용자가 공유 대상을 선택하고, 그 외에는 PNG를 저장해 카카오톡 등에 직접 첨부한다. 자동 전송하지 않는다.
- 열차 로딩 화면에는 목적지 음성 안내·다시 듣기·소리 끄기가 있다. 브라우저 한국어 음성 합성을 사용하므로 유료 API 키가 필요 없다. 자동 재생이 차단되면 안내 듣기를 누른다. 음성/한국어 지원은 기기마다 다르다.
- 스위스 객실/창밖 버튼은 시간 바로 옆에 배치한다. 처음 로딩 때 오른쪽 창밖 지형도 미리 불러온다.
- 공통 설정에 고화질/균형/가볍게를 추가했다. 3D 캐릭터는 4K 재채색과 겹치지 않는 UV, 가장자리 보정·밉맵·이방성 필터링을 사용하고, 가볍게에서는 기존 2K 모델을 사용한다. 모델 해상도 선택은 다음 객실 로딩에 적용되고 렌더 해상도 변경은 즉시 적용된다.
- 인천/사막의 작은 캐릭터 PNG는 확대해도 선명한 SVG로 교체했다. 인천 그림은 고해상도 캔버스에 표시하며 사막의 도트 스타일은 유지한다. 지도 공급자의 원본 영상·지형이나 원래 캐릭터의 형상을 새로 고해상도 제작한 것은 아니다.
- 화질 저장: localStorage `journey-focus-visual-quality-v1`. 고화질은 화면 배율을 최대 2배, 전체 600만 픽셀로 제한한다.

검증: 단위 테스트(중복/동점 개인 순위, 실제 4K 텍스처·관절·동작), 배포 산출물 경로, 격리된 Chrome의 여권 펼치기·도장·모바일·PNG 다운로드·공유 취소·음성 지원 분기·실제 여행 완료를 검사한다. 음성 API 테스트는 테스트 대역을 사용하므로 실제 스피커 음질을 검증한 결과는 아니다.

## 기존 기능 검증

단위 테스트에서 기존 맵 유지, 해금 기준, 짧은 여정·중도 종료·무제한 종료, 중복 지급, 지역별 수집과 잘못된 저장 데이터를 검증했다. 브라우저에서 다섯 렌더러의 자동 출발과 환승, 한 바퀴 후 서울 복귀, 종료, 완료 승차권, 모바일 여권을 확인했다. 장시간 테스트에는 격리된 테스트 브라우저의 시간 가속과 도장 fixture를 사용했다.
