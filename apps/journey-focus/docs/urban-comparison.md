# 도시 풍경 비교 · 2026-11-04

T Data 공식 역사마스터에서 2호선 뚝섬(127.047367,37.547184), 성수(127.055961,37.544581), 건대입구(127.069191,37.540373) 좌표를 조회했다.

같은 카메라 조건(지형 상대30m, 경사-4도, 화각65도), 원본 필터, LoD3+4로 각 역의 북동(20도)/남서(200도) 방향을 비교했다. 실제 플랫폼·좌석 높이나 선로 좌표는 아니다. 첫 뚝섬 북쪽 캡처는 지형 로딩 완료가 아니었으며 나머지는 지형 완료 상태였다. 지형 완료는 모든 건물 텍스처 완료를 보장하지 않는다.

| 지점 | 관찰 |
|---|---|
| 뚝섬 북쪽 | 큰 아파트 외벽이 화면을 가림. 창문 재질은 표시됨 |
| 뚝섬 남쪽 | 중저층과 고층이 함께 보여 정지 구도가 비교적 좋음 |
| 성수 북쪽 | 가까운 건물 면이 화면을 크게 차지하고 재질 확대가 거침 |
| 성수 남쪽 | 가까운 유리 외벽에 시야가 거의 막힘 |
| 건대입구 북쪽 | 가까운 큰 건물이 화면 대부분을 가림 |
| 건대입구 남쪽 | 저층 시가지와 스카이라인, 하늘이 함께 보여 세 지점 중 정지 구도가 가장 나음 |

뚝섬/건대입구에서 동남쪽110도 방향으로150m 직선 카메라 이동도 시험했다. 실제 선로를 검증한 이동이 아니다. 뚝섬은 이동 후 가까운 건물에 가려졌고 건대입구에서는 도로 축 방향으로 더 열린 도시 화면이 나왔다. 시험 이동은 별도 QA 탭에서 실행했고 기본 여정은 변경하지 않았다.

추천: 건대입구 주변을 도시 시안 첫 후보로 삼되, 실제 선로 선형을 확보한 뒤 충돌·시야·플랫폼 높이를 재검증한다. 도시 데이터도 외벽 해상도, 촬영 그림자, 단순한 흰 면이 일부 남아 있다. 실사 품질 완성을 의미하지 않는다.
