# 실제 선로 기반 도시 구간 비교 · 2026-11-04

이전 urban-comparison.md의 임의 직선 이동과 구분한다. OSM 공식 읽기 API로 2호선 본선 way 1458437482와 625534094를 확보했고 두 way의 연결 노드가 일치하는지 검사했다. 성수지선·7호선·분당선·분기기 선형은 사용하지 않았다.

- 뚝섬–성수: 선로 노드6개, 약921m
- 성수–건대입구: 선로 노드13개, 약1,192m
- 끝점은 역 중심을 선로에 억지로 연결하지 않고 가장 가까운 OSM 노드를 사용했다. T Data 역 중심과의 차이는 뚝섬4.7m, 성수111.0m, 건대입구46.0m. 따라서 정확한 승강장 끝점이나 영업거리가 아니다.
- 진행은 뚝섬→성수→건대입구. 왼쪽/오른쪽은 각 지점 선로 접선 기준±90도다. OSM 선로 중 한쪽을 선택했으며 실제 열차 운행 방향/승강장·신호 규칙까지 검증하지 않았다.
- LoD3+4, 필터 원본, 화각65도, 경사-4도. 좌우의25/50/75% 지점을 캡처하고 선로 좌표를 따른 연속 이동도 실행했다.

## 중요한 높이 한계

OSM bridge=viaduct / layer=3 표기는 확인했으나 layer3은 높이3m를 뜻하지 않는다. 실제 레일 표고는 확보하지 못했다. 지형+12m와 지형+30m를 비교용으로 시험했다. 두 값 모두 실제 차창 높이로 검증되지 않았다. 수평 선형을 지킨 시험이지 실제 차창 전체 재현을 완료한 것이 아니다.

| 구간 | 지형+12m에서 관찰 | 지형+30m 중간 지점 관찰 |
|---|---|---|
| 뚝섬–성수 | 외벽이 보이는 일부 지점도 있지만 구조물 면이 화면을 가리거나 카메라가 모형 내부처럼 보임 | 양쪽 도시 외벽이 보임. 오른쪽이 상대적으로 트임 |
| 성수–건대입구 | 여러 지점에서 구조물/모형 면이 화면 대부분을 가림 | 왼쪽은 가까운 건물에 막힘. 오른쪽은 넓은 도시 시야 |

판단: 도시의 외벽 데이터는 유용하지만 정확한 고가 높이와 지도 모형 간 정렬을 해결하기 전에 전체 구간을 실제 차창 품질로 확정하면 안 된다. 다음 작업은 실제 선로 표고·고가 구조물의 높이 확인과 모형 겹침 진단이다. 수평 경로를 건물 회피용으로 옮기지 않는다. 시안 제작 우선 후보는 성수→건대입구 오른쪽이지만30m 시험에서의 잠정 판단이다.
