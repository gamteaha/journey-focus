# 2호선 본선과 무제한 집중

첫 화면에서 `∞ 무제한`을 선택하면 시작 역을 정하고 종이표/교통카드로 탑승한다. 도착역은 자동으로 시작 역과 같은 순환 지점이 되며, 표에는 `2호선 순환 · ∞ 무제한`을 표시한다. 본선 43개 역을 계속 돌고 직접 종료할 때까지 세션이 끝나지 않는다. 시간 정하기로 돌아가면 현재 화면에서 마지막으로 선택했던 유한 시간을 복구한다.

## 이동과 시간

- 한 바퀴는 앱에서 정한 90분이다. 실제 운행 시간표가 아니다. 약 49km의 원래 선로를 일정한 공간 속도로 이동한다. 유한 집중 모드의 느린 추천 속도와 별도인 무제한 모드의 주행 기준이다.
- 선택한 역의 OSM 정차 노드에서 시작해 같은 노드로 돌아온 뒤 계속 진행한다. 출발점을 잇는 가상 직선이나 도착 후 되감기는 경로를 만들지 않는다.
- 누적 경과 시간÷5400초의 정수 부분은 완료한 바퀴 수, 소수 부분은 현재 바퀴의 위치다. 1바퀴 이전에는 `0바퀴 완료`를 표시한다.
- 좌표뿐 아니라 접점 양쪽 12m의 시선 방향도 고리로 이어 계산해, 바퀴 경계에서 방향을 다시 돌리지 않는다.
- 전광판에는 현재/다음 역과 완료한 바퀴 수, 창밖 화면의 시계와 캐릭터 머리 위에는 누적 집중 시간을 표시한다.
- 일시정지 동안은 시간·거리·바퀴 수가 진행하지 않는다. 재개하면 같은 지점에서 이어지고, 직접 종료하면 누적 시간·완료한 바퀴 수·이동 거리를 브라우저 기록에 저장한다.

## 데이터

[OSM 내선순환 관계 4729409](https://www.openstreetmap.org/relation/4729409)의 공식 API 응답에서 23개 선로 way를 연결했다. 554개 좌표의 첫/끝 노드 ID가 같고 정차 노드 43개가 모두 그 선로 안에 있는지 검사한다. 성수지선과 신정지선은 포함하지 않는다. 출처·way 목록·터널 구간 정보·ODbL 1.0 표기는 `public/data/line2-loop.json`에 남긴다.

역 선택 목록은 기존 서울 T Data의 2호선 GEOM API를 사용하되, 부역명을 정리하고 본선 역 목록으로 제한한다. 수평 선형 후보이며 실제 레일 표고와 운행 규칙을 검증한 것은 아니다. **지하 구간은 현재 터널 내부가 아닌 지상 지도에서 조망한다.**

`node scripts/build-line2-loop.mjs`로 재생성한다. `--cached`는 무시되는 `tmp/line2-loop-source/`의 기존 응답을 사용한다. VWorld 지형/건물 파일과 인증키는 저장하지 않는다.

## 상태 저장

무제한 시간은 JSON에서 명시적인 `duration: null`로 표현한다. `Infinity`는 저장/발급 입력으로 받지 않는다. 시계 스냅샷은 `unlimited: true`를 전달하며 유한 시간 완료 타이머를 예약하지 않는다. 초기 대기 상태의 0초와 구별한다.

설정은 무제한 여부와 출발역을 기억한다. 새로고침 후 실행 중이던 시계를 자동 재개하지는 않는다. 종료 기록에는 `unlimited`, `laps`, `distanceMetres`, 실제 경과 시간을 저장한다. 무제한 종료를 목표시간 완주나 실제 역 도착으로 표시하지 않는다.

## 검사

- `tests/loop.test.mjs`: 43개 출발 지점의 연결과 접점 방향, 지선 제외, 유한 경로의 시청 경계 통과, 8바퀴 이상 자동 종료하지 않는 시계, 일시정지·재개·종료, 표와 설정의 null 직렬화.
- `node scripts/loop-check.mjs`: 실제 브라우저에서 43개 역 선택, 시간/무제한 전환, 종이표/카드 화면 크기, 실제 객실의 공부 시간 표시, 일시정지와 종료 기록, 설정 복구. **브라우저 테스트 시계만 3시간 가속**해 2바퀴를 확인한다. 실제 3시간 연속 렌더 부하 시험을 뜻하지 않는다.
- 캡처/결과는 루트 `tmp/loop-qa/`에 저장한다. 제품에는 테스트용 시간 가속 기능을 넣지 않는다.
