# 6번 기본 스타일과 영상 시험

2026-11-04 사용자가 정면광 재비교에서 고른 6번을 기본 적용했다.

- `public/style-filter.mjs`: 카메라 방향을 매 프레임 따라가는 DirectionalLight 1.2, 그림자 끔, AO(intensity 2, bias .1, lengthCap 1, stepCount 16), 기존 색감/안개 셰이더 70%.
- 스타일 선택에서 원본으로 돌아가면 기존 조명·AO 상태를 복구한다. AO 미지원 장치에서는 AO를 생략하고 상태를 표시한다.
- 지도 입력 차단, 성수→건대입구 실제 OSM 수평 선형, 지면+30m 시험 높이는 유지한다.

## 만들어진 결과

`http://localhost:5173/video-pilot/`에서 원본과 6번 10초 영상 비교 및 다운로드.

`scripts/record-route-clips.mjs`를 앱 디렉터리에서 실행하면 전용 QA Chrome(9223)에서 녹화한다. 결과는 저장소 루트 `tmp/route-video-pilot/`에 저장된다. 성수→건대입구 경로 진행률 .42→.58, 약 191m를 이동한다. WebM VP8 1280×800이며 출처를 영상 하단에 넣는다. 현재 QA 환경의 지도 갱신은 약 16fps 수준으로 매끄러운 최종 영상은 아니다. 지도 원본에 없는 건물 표면이나 지형 디테일을 복원한 결과가 아니다.

## 다음 단계와 실행 범위

실제 AI 동영상 변환은 미실행. 현재 세션에 호출 가능한 동영상 변환 도구가 없다. 기존 10번은 정지 이미지 시안이며 영상 결과가 아니다.

영상 변환 서비스가 연결되면 원본 10초부터 시험한다. 건물 윤곽·창문·도로·카메라 움직임 유지와 프레임 간 깜빡임을 비교한 뒤, 통과한 노선 구간을 사전 제작해 재사용한다. 서비스와 설정에 따른 비용을 확인해야 하며, 실시간 사용자별 AI 변환이나 유료 생성 호출은 현재 구현하지 않았다.
