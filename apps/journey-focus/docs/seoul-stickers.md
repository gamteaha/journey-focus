# 서울 여행 스티커 8종

사용자 제공 스티커 모음 이미지를 스타일 참고로 내장 image_gen 도구로 제작했다. 모든 최종 PNG는 생성 원본을 그대로 복사했으며 알파 채널을 보존한다. 별도 API 키나 CLI를 사용하지 않았다.

- 미리보기: `public/images/seoul-stickers/index.html` (직접 열기 가능)
- 웹 경로: `/images/seoul-stickers/index.html`
- 개별 PNG: 같은 디렉터리. 티켓에는 궁궐·남산타워·전철·회중시계·하트 5종을 사용하며, 모바일은 장식을 줄인다.
- 한강 다리는 특정 실재 다리의 정밀 재현이 아닌 장식용 그림이다.
