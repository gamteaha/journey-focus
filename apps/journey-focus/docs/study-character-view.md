# 출발 후 캐릭터 공부 화면

사용자가 제시한 맞은편 좌석 정면 사진을 구도 참고로 삼았다. 출발 전에는 기존 통로 이동/좌석 미리보기를 유지한다. 출발 후 앉아 있는 상태에서 ‘캐릭터’ 화면을 보면 카메라가 맞은편에서 해당 좌석 줄을 정면으로 바라본다.

- 7인/3인 좌석 줄을 실제 모델의 배치로 구분한다. A/B 어느 쪽이든 카메라와 캐릭터 사이에 통로를 두며, 카메라의 종방향 위치와 시선의 종방향 위치를 맞춘다.
- 넓은 화면에서는 좌석 줄을 함께 보여주고, 좁은 화면에서는 내 캐릭터를 중심으로 보여준다. 화면 비율에 맞춰 시야각을 조절하고 낮은 가로 화면에서는 시간표를 작게 표시한다.
- 캐릭터 머리 위 ‘공부한 시간’은 부모의 `SessionClock.elapsed`를 초 단위로 내림해 표시한다. 남은 시간을 재활용하거나 별도 타이머를 누적하지 않는다. 일시정지와 종료 시 값이 멈추며, 창밖을 보다가 돌아와도 같은 시간이 이어진다.
- 캐릭터 화면에서는 오른쪽 남은 시간 숫자를 접고 일시정지/종료만 남긴다. 창밖 화면에서는 기존 남은 집중시간을 표시한다.
- 시간표는 매 프레임 캐릭터의 3D 머리 위치를 화면 좌표로 변환해 배치한다. 화면 밖으로 나가지 않도록 제한하고, 남은 시간/설정 버튼과 겹치지 않도록 배치한다.
- 앉아 있는 동안 이동 패드/큰 이동 안내를 숨기고 아래쪽에 일어나기/창밖 보기만 둔다. 일어나거나 다른 자리를 고르는 기능은 유지한다. 정면 화면에서 의자를 클릭할 때 카메라 뒤쪽 좌석의 선택 영역이 가로막지 않도록 보이는 쪽 좌석만 검사한다.

캐릭터는 기존 임시 메시를 사용한다. 이번 변경은 구도와 누적 시간 표시이며 책, 독서 모션, 캐릭터 원본 교체는 추가하지 않았다. 공부 시간은 집중 여정 시계 기준이므로 자리 변경만으로는 일시정지되지 않는다.

## 검증

`npm test` 59개, `npm run check`.

전용 QA Chrome(기본 9224)에서 `node scripts/study-view-check.mjs`: 출발 전 시간표 숨김, 양쪽 좌석 정면 구도, 실제 누적 시간, 일시정지 중 값 고정, 남은 시간과의 합, 화면 전환 후 시간 유지, 일어나기/반대편 재착석, PC/휴대폰/가로 화면 배치를 확인한다. 캡처와 결과는 루트 `tmp/study-view-qa/`에 저장한다.
