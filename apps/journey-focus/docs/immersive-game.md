# 객실 전체 화면과 좌석 상호작용

승차권 확인 이후에는 객실/창밖이 브라우저 뷰포트를 채운다. 브라우저 자체의 탭과 주소창을 숨기는 전체 화면 권한은 사용하지 않는다.

- 기존 흰색 헤더·하단 시간/진행률·출발 영역은 게임에서 표시하지 않는다.
- 위쪽 중앙의 전광판 형태 안내에 이번 역·다음 역과 여정 진행률을 표시한다. 실제 운행 정보가 아닌 집중 여정의 진행 상태다. 현재 지원 노선은 성수–건대입구 양방향이다.
- 집중 시간은 출발 후 오른쪽 위에 나타난다. 같은 패널에서 일시정지·이어가기·종료한다. 출발 전에는 시간 패널을 숨기고 준비 상태와 출발 버튼만 아래쪽에 표시한다.
- 왼쪽 위 설정 메뉴에서 승차권·기록·음향·화면 품질·풍경 스타일·자료 출처를 연다. 설정을 여는 동안 캐릭터 입력은 중지하고 닫으면 복구한다. 집중 시간은 설정을 열어도 계속 흐른다.
- 객실/창밖 전환 버튼은 게임 안에 남긴다. 창밖 지도는 사용자 드래그로 움직이지 않는다.

## 좌석 선택

드롭다운과 모든 의자 위의 초록 고리를 제거했다. 좌석마다 FBX 치수에 맞춘 쿠션·등받이 하이라이트를 별도 배치한다. 선택 가능한 의자를 가리키면 민트색, 선택/이동 중에는 노란색, 현재 착석 좌석은 하늘색으로 표시한다. 원본 FBX가 좌석별 독립 재질을 제공하지 않아 의자 표면에 색상 레이어를 씌우는 방식이다.

좌석 클릭은 미리보기만 변경한다. 캐릭터 옆에 선택한 좌석 번호와 ‘앉기’ 버튼이 나타나고, 버튼 또는 E로 확정해야 통로를 따라 이동해 앉는다. 다른 좌석을 미리 볼 때는 기존 좌석을 유지한다. 이동 중 다른 의자를 클릭하면 기존 이동을 취소하고 새 선택을 확인받는다. 이동 키를 누르면 선택/자동 이동을 취소한다.

의자를 직접 고르지 않은 상태에서는 가장 가까운 의자 하나를 후보로 보여준다. 바닥 클릭과 WASD/방향키, 터치 방향 버튼을 유지한다. 말풍선은 캐릭터의 화면 좌표를 따라가며 화면 밖으로 나가지 않도록 제한한다.

## 검증

- `npm test`: 59개. 미리보기만으로 이동하지 않음, 확인 후 착석, 다른 좌석으로 변경, 이동 취소 검증을 포함한다.
- `npm run check`: 문법 검사.
- 전용 QA Chrome(기본 9224)에서 `node scripts/game-check.mjs --reload`: 실제 3D 좌석 포인터 선택과 확인, 타이머 노출 시점, 전광판, 설정, 착석 변경, 창밖 전환/지도 입력 잠금, 객실 지도 2FPS 예산, 이탈 확인 후 재입장.
- `node scripts/boarding-check.mjs`: 기존 종이/카드 입장, 캐릭터 색상, 재발급과 이탈 확인 수락·취소 검사.
- 전체 화면 및 넘침 검사: 1440×900, 1366×650, 1100×700, 390×844, 844×390. 결과/캡처는 루트 `tmp/game-qa/`에 저장한다. `scripts/cabin-check.mjs`는 새 게임 검사로 연결하는 호환 진입점이다.

실시간 창밖을 객실 유리에 합성하거나 다른 친구의 접속을 동기화하는 기능은 이번 변경에 포함하지 않는다.
