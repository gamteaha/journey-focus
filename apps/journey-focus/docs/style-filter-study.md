# 실사풍 후처리 시험 · 2026-11-04

로컬 개발 앱의 지도 왼쪽 위 ‘풍경 스타일’에서 원본 / 실사풍 · 시험을 전환한다. 강도 0~100%, 기본 70%. 기본 스타일은 원본이며 새로고침 후에도 원본으로 시작한다. 숲 보강 버튼과 독립적이다. 공개 hosted 소스에는 아직 반영하지 않았다.

현재는 약한 5탭 선명도, 채도 감소, 어두운 영역 보정, 깊이 텍스처를 이용한 거리 안개를 단일 GPU 후처리로 적용한다. 새로운 광원·그림자·AI 생성·지형 해상도 복원은 적용하지 않는다. SDK에서 Cesium 1.99, depthTexture 지원과 실제 셰이더 컴파일을 확인했다.

실제 브라우저에서 stage ready/enabled, 강도 0%, 원본 전환을 확인했고 지도 오류 표시는 없었다. 기존 테스트 48개와 문법 검사도 통과했다. T Data 연결 문제로 전체 여정 이동·장시간 프레임 성능은 이번에 검증하지 않았다. 테스트: node scripts/style-filter-check.mjs.

소스 public/style-filter.mjs, 연결 public/map.mjs, 서버 허용 경로 server.mjs. 원본은 후처리를 비활성화하므로 원본 텍스처나 건물 레이어를 바꾸지 않는다. 산과 추가 식생의 실제 조화·이동 중 안정성은 사용자의 화면 평가와 추가 측정이 필요하다.
