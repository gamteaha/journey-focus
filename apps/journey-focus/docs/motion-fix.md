# 300m 시안 이동 안정화 · 2026-11-03

사용자는 이동이 자연스럽지 않으며 남은 28/22/17/11초에 집이 보인다고 보고했다. 집은 약 60m 간격의 재구성 배치이고 시안 속도는 약 10m/s여서 약 6초 간격으로 보이는 것과 부합한다. 배치와 이동 시간은 유지했다.

## 확인한 원인

수평 경로의 300m 구간을 60Hz로 계산했을 때 진행 방향의 급격한 꺾임은 없었다. 실제 브라우저의 30초 카메라 측정에서는 남은 11초 부근에서 한 프레임 높이가 약 4.9m 증가한 뒤 다시 감소했다. 그 순간 지형 높이 조회값도 함께 변했다. 검증용 페이지에서 충돌 보정을 꺼도 같은 위치에서 재현되어 충돌 옵션은 변경하지 않았다.

한 점의 지형 표고를 즉시 카메라에 적용하던 것이 큰 높이 튐으로 이어졌다. 이 결과를 실제 선로의 높이 변화로 해석하지 않는다.

## 변경

- 시안 카메라만 진행 방향 전후 6m 내 7개 높이의 중앙값을 참고한다.
- 이 고정 백양리 구간에서 미로딩 타일의 음수 높이와 주변의 크게 다른 임시 표본을 제외한다.
- 이동 중에는 높이 변화 속도를 제한하고 완만하게 따라간다. 높이 조회는 최대 약 10Hz로 제한하고 카메라는 프레임마다 갱신한다.
- 첫 시작 전에 현재 시점을 정렬한다. 일시정지·완주 직후에는 갑자기 원본 높이로 되돌리지 않는다.
- 처음으로/위치 슬라이더/다시 보기의 명시적 위치 변경은 즉시 재정렬한다.
- 일반 지도·비교 모드와 건물/식생 배치는 변경하지 않았다.

## 검증

- 단위/서버 테스트 18개 통과, 문법 검사 통과
- 실제 30초 이동 측정과 전체 시안 완주 확인
- 일시정지, 위치 슬라이더, 다시 보기의 시작 정렬 확인
- 로딩 중 취소, 모델 정리, 원본 지도 복원, 모바일 가로 넘침 검사 통과
- 독립 코드 리뷰의 다시 보기 높이 상태 지적 수정 후 재검증

재현: `node scripts/measure-motion.mjs after`, `node scripts/scenery-check.mjs`. 별도 QA Chrome(CDP 9223)과 로컬 서버가 필요하다. 실제 선로 표고는 여전히 미검증이며, 이 카메라는 지형을 평활화한 실험 경로이다.
