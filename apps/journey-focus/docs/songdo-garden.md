# 송도 정원 여행

2026-11-07 사용자 요청으로 팀 데모를 기존 앱의 세 번째 여행지에 연결했다.

- 원본: https://journey-focus-window-demo.hai-labs-003.chatgpt.site/
- 사용자 확인: 실제 역을 재현한 것이 아닌 가상 여행. 밝은 수변 일러스트, 둥근 창틀, 작은 시간 표시, 우측 하단 횃불이를 유지한다.
- `/ ?destination=songdo` (공백 없이): 공통 승차권/교통카드 → 개찰 → 공통 열차 도착 화면 → `/songdo/?ticket=…`.
- 노선은 창작 정거장 7개. 실제 인천 1호선 역·거리·시간표·API를 사용하지 않는다. 세계 지구본 핀은 여행의 테마 지역만 표시한다.
- 유한 여정은 선택한 시간에 도착하도록 진행 표시를 조절한다. 배경 스크롤 속도는 시간과 독립적이다. 무제한은 선택 구간을 정거장당 5분으로 왕복하며 사용자가 종료한다.
- 횃불이는 원본 이미지 색을 유지한다. 블루·민트·앰버는 객실 좌석의 테마 색이다.
- 숨겨진 탭에서는 자동 일시정지한다. 기록은 `journey-focus-songdo-history`에 분리한다. 새로고침하면 티켓은 유지하지만 진행 중 타이머는 초기화한다.

## 출처와 파일

사용자가 통합하도록 제공한 위 팀 데모의 공개 `src/style.css`, `src/boarding.css`, `src/illustrated-scene.mjs`, `src/session.mjs`, `src/journey.mjs`, 객실 HTML 및 상호작용 코드를 기반으로 한다. 원본의 실제 인천 역 관련 정보·별도 발권 화면은 사용하지 않는다. 호스팅 서비스가 삽입한 보안 스크립트는 가져오지 않았다.

`public/songdo/input/`의 네 PNG는 위 데모의 동일 이름 공개 파일을 그대로 가져왔다. 풍경 2장은 데모의 생성 일러스트, 캐릭터 2장은 데모가 안내한 인천대학교 횃불이 이미지다. 별도 라이선스를 새로 부여하지 않으며 원본 데모 및 캐릭터 출처 링크를 앱의 여정 안내에 유지한다.

공통 티켓은 `public/songdo-ticket.mjs`, 데이터/검증은 `src/songdo-journey.mjs`, 객실/풍경은 `public/songdo/`에서 관리한다. Cloudflare의 중첩 HTML 경로는 worker와 wrangler 설정에 명시한다.
