# 현재 기본 여정 · 2026-11-04

기본 여정은 2호선 성수→건대입구, 오른쪽 창가로 변경했다. T Data 역사마스터에서는 이 두 역의 2호선 좌표를 필터링한다. public/data/seongsu-konkuk.json의 OSM 본선 좌표13개로 약1.19km 수평 경로를 이동한다. 역 중심과 선로 끝점은 서로 다르며 실제 운행거리나 승강장 위치 검증값이 아니다. source·wayIds·ODbL 출처는 데이터 파일에 보존했다.

시점은 진행 방향+90도, 지형+30m 시험값. 실제 고가 표고와 차창 높이를 검증한 것은 아니다. 기본25분 및1/5/50분은 집중 세션 시간으로 실제 운행시간이 아니다. 기본 건물은 LoD3+4, All은 조사용 선택으로 유지한다. 실사풍 필터는 선택 사항이다.

이전 경춘선 근경/산 숲 시안은 도시 여정에서 숨겼다. 원본 소스·자료는 보존한다. 비교창의 경춘선 영상도 이전 노선 참고 자료로 명시했으며2호선 영상으로 오인하면 안 된다. 공개 hosted 소스는 변경하지 않았고 로컬 앱만 수정했다.
